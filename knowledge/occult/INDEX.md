# 神秘学语境库（occult）

这个目录只在用户打开**神秘学模式**时才参与检索；关着的时候这些资料完全不进上下文。

## 怎么往里放资料

- 直接在本目录下放 `.md` 文件即可，子目录也行（例如 `occult/rituals/所罗门小钥匙.md`）。
- 文件名就是检索结果里显示的路径，起得具体一点更好命中：「赫尔墨斯主义 · 七个原则.md」比「笔记1.md」好。
- 记得写 README 或 INDEX（本文件）当导航——`INDEX.md` 本身不参与检索。

## 写什么最有用

1. **体系与源流**：赫尔墨斯主义、卡巴拉生命树、炼金术三阶段、威卡年轮、行星时与月相。
2. **象征对照**：元素—方位—颜色—行星—塔罗小牌花色的对应表。
3. **仪式的人类学记述**：降神会、通灵板、祈请与驱逐在历史上怎么做的（记述，不是操作手册）。
4. **心理与临床视角**：把神秘体验讲成心理机制时可靠的框架（荣格共时性、解离、想象性同伴）。
5. **边界与风险**：哪些做法在现实里有伤害风险（禁食、缺氧、致幻物、独处长时间通灵、付费开光），该怎么提醒。

## 不要写什么

- 逐步的实操指令（召唤步骤、剂量、时长、器械清单）。
- 任何声称可以验证的通灵结果、亡者原话、附身诊断。
- 医疗 / 法律 / 财务的具体结论。

这些不是文风问题：`prompts/occult.zh.md` 里写死了「不给可能伤到人的实操」，资料里出现类似内容也会被当作文本引用，仍然受那条规则约束。

## 检索行为

- 走 `agent/knowledge.py` 的关键词打分，`top_k=3`、单轮最多 9000 字。
- 关闭神秘学模式时，`knowledge.retrieve(..., include_occult=False)` 会把这些文件过滤掉，`/api/knowledge` 也不列出它们。

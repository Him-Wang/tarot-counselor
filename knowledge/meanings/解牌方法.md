# 解牌方法：逆位、牌阵与使用原则（原创精简笔记）

- 标签：解牌 / 方法 / 逆位 / 牌阵 / 单张 / 三张 / 凯尔特十字 / 正逆位
- 什么时候读：需要确认逆位如何理解、某牌阵位置的含义，或如何把牌意落到问题时

> 依据 RWS 传统与《塔罗智慧》《21世纪的塔罗书》《其实你已经很塔罗了》三书要义，用原创中文重写的精简笔记。

## 逆位如何理解

逆位不是"坏"，也不是"反义词"那么简单。常见的四种读法，按情境取用：

- **能量受阻**：正位的力量被堵住、延迟或转向——本来能流动的，现在卡住了。
- **能量内化**：本来向外的表达转向内在，或反之。不一定好坏，只是方向变了。
- **过度或不足**：某种特质太多（泛滥）或太少（匮乏）。
- **需要调整的信号**：提醒你留意这个议题——它可能没被好好处理。

具体取哪一种，要结合牌阵位置和来访者的实际处境判断，不套公式。若不确定，就说明这是常见的韦特理解，不强行断言。

## 标准牌阵的位置含义

### 单张
- 指引：此刻最需要留意的核心，一个焦点。

### 三张（过去 / 现在 / 未来）
- 过去：已经发生、正在退场的影响。
- 现在：当下的处境与态度。
- 未来：按当前趋势可能的发展（不是注定，可以改变）。

三张牌要连起来读：看过去如何走到现在、现在又如何指向未来，而不是三张各自孤立。

### 凯尔特十字（十张）
1. 现状：问题的核心与当前状态。
2. 阻碍：横在面前的挑战或阻力。
3. 意识目标：你想要的、意识层面的方向。
4. 潜意识根基：隐藏在表面之下的动机与根源。
5. 过去：刚过去、正在消退的影响。
6. 未来：即将到来的发展。
7. 自我：你在这个局面中的状态与角色。
8. 所处环境：外部条件与他人影响。
9. 希望与恐惧：内心深处的期待与担忧。
10. 最终结果：综合以上之后的可能结局（可改变）。

## 解牌顺序（必须遵守）

每张牌按固定顺序解：**原本牌意 → 牌阵位置 → 对应问题 → 落到情境**。

1. **原本牌意**：这张牌在韦特体系里的核心含义（正位或逆位），以 `meanings/` 里的牌义笔记为准。
2. **牌阵位置**：把牌意放进它所在的位置——同一个"逆位"在"阻碍位"和"结果位"读法不同。
3. **对应问题**：把位置与来访者问的事对上，说明牌在回应问题的哪个层面。
4. **落到情境**：最后才联系来访者的处境，落脚必须由牌意推出，而不是先有结论再找牌背书。

## 禁忌

- 不主观投射（"这张牌映出的，也许是……"）——先有结论再套牌意。
- 不编造牌意、不自由发挥；牌意不确定时，说明这是常见的韦特解释。
- 不因为牌不好听而粉饰，也不预言具体事件。
- 抽到什么解什么；不换牌、不补牌、不挑牌。
- 风险评估、诊断倾向、干预选择绝不从牌里来——那些属于专业判断，不是塔罗的职责。

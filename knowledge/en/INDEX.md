# Olivia Knowledge Base — English Mirror

This directory mirrors the Chinese knowledge base under `knowledge/` for `language: "en"`.
It uses the same layout (`meanings/`, `readings/`, `ethics/`, `skills/`, `spreads/`, `occult/`); when a file is missing, loading falls back to the Chinese original. `INDEX.md` itself is navigation and is not retrieved.

## Contents
| Directory | What it covers |
| --- | --- |
| `meanings/` | All 78 RWS card meanings (22 major arcana, 4 suits), card relationships, reading methods |
| `readings/` | Reading flow, single-card deep read, reversed cards, court cards |
| `ethics/` | Crisis & referral — safety overrides every reading rule |
| `skills/` | Empathic listening |
| `spreads/` | Spreads quick reference (authoritative positions live in `agent/spreads.py`) |
| `occult/` | Occult context library — only retrieved when occult mode is on |

## Boundaries
This content is for reflection and entertainment, not a substitute for medical, legal, financial, or mental-health advice. In a crisis, local emergency services and crisis lines come first — see `ethics/crisis-and-referral.md`.

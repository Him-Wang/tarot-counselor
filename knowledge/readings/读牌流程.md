# 读牌流程：从一句问题到一件可做的事

- 标签：解牌流程 / 提问 / 抽牌 / 落点 / 收束 / 边界 / 韦特
- 什么时候读：准备开一次占卜、或来访者问「到底该怎么读」时，按这份顺序走

> 依据 RWS 传统，参考《塔罗读牌21式》《韦特塔罗全攻略》《塔罗逆位精解》的方法要点，用原创中文重写。流程是顺序，不是公式；每一步都可以停下来问来访者。
>
> 适用范围：只做韦特（Rider–Waite–Smith）系统。

## 0. 先把问题说清楚

- 具体到「谁、什么时候、想决定什么」。「我最近运气怎么样」这种问题，先请对方挑一个最在意的场景。
- 把命运型问题翻译成选择型问题：「他会不会回来」→「我在这段关系里还想做什么、还能做什么」；「这份工作好不好」→「接与不接，各自要付什么代价」。
- 允许对方说「我不知道要问什么」。这时用单张，问题写成「我现在最需要看见什么」。
- 三类不接：需要医生、律师、金融专业人士判断的具体决策；生死与诊断；第三方的隐私（对方不愿说的事）。

## 1. 选牌阵

- 一个问题配一个牌阵。位置越多，越容易读成流水账；能三张说清就不用十张。
- 抽之前先把每个位置在问什么讲明白。位置含义不清楚，后面一定打架。
- 常见选择：单张（一个焦点）、三张（过去/现在/未来）、关系牌阵（双方与关系本身）、二选一（两条路各自的代价）、凯尔特十字（复杂局面的全景）。

## 2. 抽牌

- 不放回、随机、正逆位都算。牌由系统内核熵真随机产生，不可复现——抽到什么读什么，本身就是自证。
- 不换牌、不重抽、不因为「这张不好」再抽一副。抽到什么读什么。
- 补牌有前提：原牌已经读完、来访者说得出为什么要补、补来的牌只作补充视角，不替换原牌。

## 3. 单张的四步落点

1. **牌意**：这张牌在韦特体系里的核心含义，按正位或逆位取。
2. **牌位**：把牌意放进它所在的位置。同一个逆位，在「阻碍」和「结果」位置读法不同。
3. **问题**：说明这张牌在回应问题的哪一层——是事实、是感受、还是选择。
4. **情境**：最后才联系来访者的具体处境。顺序不能倒：先有结论再找牌背书，是最常见的自欺。

## 4. 多张连读

单张读完再连。看元素怎么相处、数字走到哪一步、大牌与小牌的比例、宫廷牌指的是谁、整组牌像不像一个故事。具体工具见同目录 `../meanings/牌间关系.md`。

## 5. 收束

- 用两三句话总结这组牌在说什么，然后给一个**一周内做得到**的小动作：写下来、问一句、约一次、停一天。
- 不给时间点承诺（「三个月内一定」），不给他人行为的断言（「他一定会回来」），不替来访者做决定。
- 收尾问一句「哪一部分对你有用，哪一部分不像」。来访者的核对，比解读本身更能校准。

## 6. 留下记录

记下牌阵、问题、当时的判断。过一段时间回看，比凭记忆复盘可靠得多；也会慢慢看出自己惯常的盲区。

## 7. 知道什么时候停

- 出现自伤、他伤、侵害线索：立刻离开塔罗角色，先给求助资源与转介，不抽牌、不解读。
- 同一件事短期内反复问：说明缺的不是答案，而是一个决定或一次对话。可以把这句话直接告诉对方。
- 读不出来就说读不出来。宁可给离线整理（牌位 + 传统牌意），也不要编一段像解读的话。

## 常见错误对照

| 错误 | 表现 | 改法 |
|---|---|---|
| 先有结论再找牌 | 「你是不是最近压力很大」然后硬套 | 先描述牌面，再让来访者说像不像 |
| 逆位一律读坏 | 看到逆位就说「不好」 | 按受阻/延迟/过度/内化分别说，见 `逆位读法.md` |
| 用「牌说」躲责任 | 「牌显示你应该分手」 | 换成「这组牌里有一个想离开的信号，你怎么看」 |
| 一张牌讲十分钟 | 把联想全倒出来 | 一张牌抓一个核心 + 一个落点 |
| 替人做决定 | 「你就该辞职」 | 列出两条路的代价，决定权还给对方 |

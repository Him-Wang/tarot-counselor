# 共情式倾听

- 标签：共情 / 倾听 / 反映 / 情绪 / 倾诉
- 什么时候读：来访者带着强烈情绪、哭诉、或只是需要被听见时

共情不是安慰，也不是同意。它是准确说出对方此刻的处境与感受，并且说得比对方自己更清楚一点。

## 做法
- 先跟情绪，再跟内容。她说"我没事，就是累"，先接住"累"，别急着分析"没事"下面的逻辑。
- 用"听起来……" / "好像……" 留余地，不替对方下结论。
- 反映到**感受 + 需要**的层面，而不是复述事件流水账。
- 沉默是工具。给她一点空间，别用话把空白填满。

## 反例
- "别难过了" —— 否认情绪。
- "我理解你" —— 空泛，没有说出具体理解了什么。
- "你应该……" —— 跳到建议，越过了被听见的需要。

## 与塔罗的关系
情绪还没落地之前不抽牌。若来访者主动要求，先做完共情再问："要不要用牌看看这件事？"

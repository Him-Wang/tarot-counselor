# 牌阵（Spreads）

- 标签：牌阵 / 布局 / 凯尔特十字 / 三张 / 关系牌阵 / 位置含义
- 什么时候读：需要选择用哪个牌阵、或需要解释某个牌位在问什么时。

牌阵的**权威定义在 `agent/spreads.py`**，`draw_cards` 工具调用时会把牌位名和位置含义
一起交给模型，所以正常解读**不需要检索本文件**。这份资料是给人看的速查表，以及给模型
在需要解释「为什么用这个阵」时的参考。

## 选阵原则

1. **先用最简单的**能回答问题的牌阵。多数问题用单张或三张就够。
2. 问题复杂、牵扯多方、需要长期脉络时，才升级到关系 / 二选一 / 凯尔特十字。
3. 不要为了显得隆重开大阵；牌位越多，解读越容易散。
4. 抽牌前说清用哪个阵、每个位置照什么。

## 快速牌阵

| 牌阵 | 张数 | 位置 | 适合 |
|---|---|---|---|
| 单张 | 1 | 指引 | 一句话就能问清的问题 |
| 三张 | 3 | 过去 / 现在 / 未来 | 想看走势的日常问题 |

## 专业布局

**凯尔特十字（10 张）**：现状 / 阻碍 / 意识目标 / 潜意识根基 / 过去 / 未来 /
自我 / 所处环境 / 希望与恐惧 / 最终结果。用在重要且复杂的问题上。

## 关于逆位

逆位按客观随机产生，抽到就解，不刻意追求也不刻意回避。逆位不等于「坏」，多数情况表示
能量受阻、内化、延迟，或需要以另一种方式表达。解牌时先讲正位核心，再说逆位改变了什么。

## 边界

- 牌阵只提供**视角**，不提供事实断言。医疗、法律、财务、他人想法，不从牌里下结论。
- 不发明牌阵，不使用不在 `agent/spreads.py` 清单里、或依赖特定牌组体系的牌阵。
- 抽到什么解什么：不换牌、不补牌、不挑牌。

# 专业知识库 · 索引

> 这是 Olivia 的「专业知识层」。把它当作按需读取的资料库，不是提示词本身。
> 每份资料开头有统一的三行元数据（标题 / 标签 / 什么时候读），检索时以标签和正文关键词命中。

## 使用规则（给 Agent）

- 遇到专业判断（倾听、共情、澄清、面质、危机分级、转介、个案概念化等）时，先在本索引里找到对应资料，再回答。
- 资料与直觉冲突时，**以资料为准**。
- 塔罗只用于打开话题与照见感受；风险评估、诊断倾向、干预选择**绝不从牌里来**。
- `meanings/` 存放经整理的 RWS 传统牌意与解牌方法（`draw_cards` 工具会随牌面返回对应牌意）；抽牌/选牌规则仍不在本目录，由工具客观产生。

## 目录

| 子目录 | 放什么 | 什么时候读 |
|---|---|---|
| `meanings/` | 传统 RWS 牌意（大阿卡纳/四花色）与解牌方法、逆位 | 解牌时按牌名取用（`draw_cards` 已随牌返回，通常无需手动检索） |
| `modalities/` | 流派：CBT、人本、叙事、焦点解决、ACT 等 | 需要某个流派的视角或概念时 |
| `skills/` | 技术：倾听、共情、澄清、具体化、面质、总结 | 决定怎么回应、怎么措辞时 |
| `issues/` | 议题：焦虑、关系、丧失、创伤、自我价值 | 来访者带来具体议题时 |
| `ethics/` | 伦理：保密、边界、危机分级、转介 | 涉及安全、边界、是否继续咨询时 |
| `supervision/` | 督导：个案概念化、反移情觉察、督导视角 | 复杂个案、需要退一步看时 |

## 资料格式模板

新建一份资料，请按这个开头：

```
# 标题

- 标签：关键词1 / 关键词2 / 关键词3
- 什么时候读：一句话描述触发场景

正文……
```

每份资料只讲一个主题；细节写进资料本身，不要堆进 SKILL 或 persona。

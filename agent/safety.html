她陪你把牌读完，

这一页把 Olivia 是什么、能做什么、做不到什么，坦白讲清楚。完整版本见仓库根目录的 SAFETY.md。

AI 身份披露：Olivia 是一个人工智能程序，不是持证心理治疗师、心理咨询师，也不是医生、律师或财务顾问。她的解读只用于娱乐与自我反思辅助——不是诊断、不是预测、不是专业意见。

涉及健康、法律、财务或人身安全的决定，请以持证专业人士的意见为准。

代码级危机闸门 SAFETY GATE

这是写在服务端代码里的检查，不是提示词里的请求。它位于 /api/chat 入口，早于视觉、抽牌、模型调用和记忆写入执行。

  • 识别五类情况：自伤 / 轻生、他人施暴或威胁、性侵、伤害他人的性意图、伤害他人。
  • 一旦命中，Olivia 不解读牌、不调用模型、不把原文写进记忆或会话簿，而是先给出支持性回应与现实求助资源。
  • 闸门在服务端，浏览器端看不到触发词，也不能跳过。
  • 它做了基本的误报抑制：明确否定句和梦境 / 虚构语境通常不会触发。

重要限制：这套检测基于正则关键词，会漏掉隐喻、谐音、间接表达和中英混写的变体；可选的「二次判断」默认关闭。不要把这条闸门当作安全网——如果你或身边的人正处于危险中，请直接联系现实中的紧急服务，不要等程序先识别出来。红队套件收录 267 个对抗用例，并公开记录了 70 个已知缺口，这是持续进行中的工作。

遇到危机，先找现实中的帮助

如果有立即的人身危险，先打电话。牌可以等，安全不能等。

  • 110 / 120中国大陆
    报警 / 急救有人正在伤害你、已经受伤或服药过量时，先打当地紧急电话。
  • 911美国 / 加拿大
    紧急电话其他地区请拨打当地紧急号码；不确定打哪一个时，优先打紧急电话。
  • ER急诊
    去最近的医院急诊已经受伤、服药过量或失去意识时，不要等待「确认严重」。

也可以先给一个信得过的人发一句：「我现在需要你陪我。」危机热线号码会随地区与时间变化，请查找你当地当前公布的危机干预 / 心理援助热线——本页刻意不列出可能过期的具体号码。如果情况紧急，请直接走上面的步骤。

Olivia 不会做的事 BOUNDARIES

  • 不预测具体未来事件：不预测日期、输赢、生死。只有显式开启「预言模式」时才会以娱乐口吻谈论预测，且明确标注「仅供娱乐」。
  • 不替你做决定：不替你选工作、伴侣或人生方向；下一步需要你亲自确认。
  • 不给医疗、法律、财务建议：不替代诊断、治疗、法律意见或投资建议。
  • 不提供有害的仪式指令：即使开启「神秘模式」，也只给象征性、文化性视角，不提供伤害自己或他人、或替代正规医疗的「仪式」步骤。
  • 遇到危机停止占卜：在风险面前，牌局让位于人和安全。

数据与隐私 PRIVACY

  • 本地优先：对话、记忆、抽牌历史存放在本机，项目自身没有遥测或分析服务器。
  • 危机原文不入库：闸门命中时，原文不会写入记忆、会话簿或占卜档案。
  • 模型服务商：正常解读会把对话上下文发给你配置的第三方模型；开启视觉桥后图片会发给第三方 VLM，受该服务商留存政策约束。
  • 局域网是明文 HTTP：把服务绑定到 0.0.0.0 后，同网络可能看到配对码与对话。请只在可信网络临时使用，不要把端口映射到公网；详细加固见仓库根目录 SECURITY.md。

反馈安全问题

  • 一般安全边界、文档或行为问题：到 GitHub 仓库 Him-Wang/tarot-counselor 开 Issue。
  • 请勿在 issue 中粘贴真实对话、记忆或密钥。
  • 可复现的安全漏洞：不要公开 issue，按 SECURITY.md 的说明用 GitHub Security Advisory 私密报告。
